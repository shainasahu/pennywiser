# PennyWiser @divhacks 2025

PennyWiser is a financial literacy tool designed for college students to simulate building a credit score based on real transactional behavior and goal achievement. It combines budgeting, spending tracking, and AI-driven guidance to help students understand financial responsibility before accessing real credit.

## Inspiration
Many college students start their financial journey without access to credit cards and struggle to build a credit score. This can lead to missed opportunities and higher interest rates later on. PennyWiser was created to help students simulate financial credibility while learning healthy spending habits, providing them with a tangible metric to present to banks when applying for their first credit card.

---

## What it does
- Track spending and set budgets.
- Monitor progress toward financial goals.
- Compute a simulated credit score based on transactional behavior and goal completion.
- Provide AI-driven guidance through a chatbot powered by Google Gemini.
- Offer a clean, beginner-friendly UI that presents data gently.

---

## How we built it
- **Frontend:** Next.js with React components for interactive charts, budgeting tools, and chatbot interface.  
- **Backend:** Flask API to handle data requests, simulate credit score computation, and provide chatbot responses.  
- **AI Integration:** Google Gemini API for personalized guidance and financial tips.  
- **Credit Score Computation:** Trained models on generated transactional data to estimate simulated credit scores. Multiple models were tested on the same dataset to achieve optimal accuracy.
